# pairwise-ssao-temporal

墙角接触阴影在相机横移时像果冻一样蠕变，半分辨率深度用点采样下采样，细杆边缘漏出亮边；法线从深度重建时把背面 F 面算反，平面出现同心圆；半球采样方向固定在屏幕空间，转身后 AO 跟着转；时域重投影只用上一帧矩阵，没有运动矢量校验，移动物体留下灰影；降噪双边半径按像素写死，4K 和 1080p 效果差一截；AO 在 sRGB 缓冲里乘直接光，暗部发灰；深度线性化近远平面传反，远处 AO 全白；历史权重按帧数累加，静止镜头越积越脏；透明物体写深度，玻璃后面的墙被误遮；AO 在 gizmo 和描边 pass 上重复相乘，边缘发黑。render/ssao_temporal.py 是核心，tests/test_ssao_temporal.py 15个红。要修的是：深度下采样用最小值并保边；法线重建按朝向修正；采样核随相机基变换；重投影加运动矢量与深度校验；双边半径按世界尺度；AO 在线性空间合成；近远平面按投影矩阵反解；历史权重按时间衰减；透明不写遮挡深度；AO 只乘一次。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
